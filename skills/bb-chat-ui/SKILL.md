# bb-chat-ui

채팅 표면만 담당한다. 메시지 본문, 메시지 액션, 컴포저다.

컴포저 초안의 `>` 인용은 호스트 멘션으로 바뀐다. `diff --git`로 시작하는 코드 인용은 변경 줄 아이콘이고, 필에는 파일 이름만 보인다. 메시지 아래 버튼으로 넣은 인용은 메시지 아이콘이고, 드래그해서 넣은 인용은 인용 아이콘이다. 필에는 첫 줄의 앞부분만 보인다. 전문은 사용자 메시지에 남지 않고, 보낼 때 에이전트에게만 전달된다. 캐럿은 필 안에 머물지 않는다. 백스페이스와 Delete는 필 전체를 지운다. 이미 보낸 사용자 메시지의 인용 문장은 한 줄 필이다. 왼쪽에 인용 아이콘이 있고, 길면 말줄임이다.

컴포저 위 변경 요약은 호스트의 `thread-prompt-banner-git-toggle`이다. 이 플러그인은 그 버튼을 필로 바꾼다. 내용은 아이콘, 줄 수, `·`, 파일 수다. 펼치기는 숨긴다. 클릭은 옆 패널의 Diff 탭을 연다.

스레드 목차는 호스트의 `[data-thread-toc]`다. 탭은 숨긴다. 카드는 마우스가 올라간 눈금의 사용자 메시지 하나만 보여 주고, 미리보기는 6줄까지다. 카드 호버는 배경색 없이 살짝 커지며, 그때도 눈금 길이와 선택 색은 유지된다. 메시지를 연 뒤 포인터가 목차를 벗어나면 카드는 닫힌다. 눈금은 오른쪽 끝에 붙고, 가까울수록 왼쪽으로 길어진다. 색이 진한 눈금은 최신 메시지가 아니라 카드에 나온 메시지다.

사이드바 패널 모션은 `bb-motion`이다. 스레드 목록의 색과 행 표시는 `bb-thread-theme`다.

전송 버튼을 눌러 보내기가 끝나면 성공 햅틱이 한 번 난다. 모바일 셸의 `haptic` capability가 있을 때만 낸다.

화면을 바꾸는 등록은 `app.tsx`에 둔다. 인용 전문은 `server.ts`가 보관하고, 전송 때 멘션으로 읽는다.
